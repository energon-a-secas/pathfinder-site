Plan the work before an agent builds it

Map goals, work, risks and open questions as typed blocks. Pathfinder names what the plan is missing, then turns the map into a brief for Claude Code, Cursor or any assistant.

Start a line with Goal:, Problem:, Who:, Metric:, Req:, Build:, Risk: or Assume: to set its type, and end a question with ?. Indented lines add detail to the line above.
